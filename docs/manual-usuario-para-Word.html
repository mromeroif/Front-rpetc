Qué hace esta aplicación

  • Certificado: solicitar el certificado de cesión con el RUT de tarea definido por su empresa; usted indica el periodo y, si aplica, RUT opcionales.
  • Consulta cesiones: comprobar si un folio, para un cedente y periodo dados, aparece entre las facturas cedidas al cesionario configurado (p. ej. Interfactor).
  • Solicitudes: ver lo que ya pidió; pulse Ver detalle y luego Obtener documento para el PDF (no se descarga desde la lista).

Cada usuario solo ve sus propias solicitudes. Para más accesos, contacte al administrador.

Antes de empezar

  1. Navegador actualizado (Chrome, Edge o Firefox).
  2. La dirección web que le entregó su organización.
  3. Usuario y contraseña; no los comparta.
  4. Si no se abre el PDF, permita ventanas emergentes para este sitio.

Menú superior

Guía 1 — Entrar y salir

  1. Abra la página e ingrese usuario y contraseña.
  2. Si es correcto, verá un aviso como Sesion iniciada como …

Problemas: Credenciales invalidas; Usuario inactivo; Token invalido o expirado. (cierre sesión y entre de nuevo).

Use Salir al terminar. Verá Sesion cerrada.

Guía 2 — Pedir un certificado (pestaña Certificado)

Archivo esperado: manual-assets/screenshots/03-inicio-certificado.png.

  1. Inicio → pestaña Certificado de cesión.
  2. Complete Desde y Hasta (obligatorias).
  3. Opcional: Deudor (opc.) y Cliente (opc.) con RUT.
  4. No modifique RUT tarea (fijado).
  5. Pulse Ejecutar. Si el PDF no abre solo, vaya a Solicitudes → Ver detalle → Obtener documento.

Guía 3 — Consultar un folio (Consulta cesiones)

Archivo esperado: manual-assets/screenshots/04-inicio-consulta-cesiones.png.

  1. Inicio → pestaña Consulta cesiones.
  2. Desde, Hasta, RUT cedente, Folio del documento.
  3. Ejecutar. Resultados en la misma página o mensaje de folio no encontrado.
Si debe reintentar una consulta de cesiones, use de nuevo Inicio → Consulta cesiones con los mismos datos.

Guía 4 — Solicitudes y detalle

  1. Menú Solicitudes.
  2. Busque o pagine. Pulse Ver detalle en la fila que necesite.

Guía 5 — Obtener el PDF (detalle)

  1. Ver detalle en la fila deseada.
  2. Revise Datos de la consulta solicitada.
  3. Obtener documento para actualizar estado y abrir el PDF.

Sesión / credencialesVolver a entrar o pedir ayuda.
